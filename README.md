# SQL Pizza Store Analysis 🍕

This project is based on SQL analysis of a Pizza Store database.  
The project demonstrates how SQL can be used to analyze sales data, customer orders, pizza categories, revenue generation, and business performance.

---

## 📌 About the Project

The database contains information about:

- Customer Orders
- Pizza Details
- Pizza Categories
- Prices and Sizes
- Order Quantities

Using SQL queries, different business-related insights were generated from the dataset.

---

## 🗄 Tables Used

### `orders`
Contains order date and time.

### `order_details`
Contains quantity and pizza order details.

### `pizzas`
Contains pizza size and pricing information.

### `pizza_types`
Contains pizza names, categories, and ingredients.

---

## 📊 Analysis Included

The project includes multiple SQL queries such as:

- Total Orders
- Total Quantity Sold
- Most Expensive Pizza
- Orders Per Day
- Revenue Analysis
- Peak Ordering Hours
- Top Ordered Pizzas
- Pizza Category Analysis
- Average Revenue Per Order
- Running Revenue Calculation
- Percentage Revenue Contribution
